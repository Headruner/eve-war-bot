## Story

**As a** bot operator, **I want** a clear log message when DOTLAN changes its page, **so that** I know the parser needs an update and the service does not crash.

## Acceptance criteria

**AC-1** — *Given* one row cannot be parsed, *when* the page is parsed, *then* that row is skipped with a warning; the other rows are processed.

**AC-2** — *Given* the page has a table but no war rows can be parsed, *when* the cycle runs, *then* `Scrape error: ... layout may have changed` is logged and the service continues.
