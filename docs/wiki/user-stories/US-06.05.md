## Story

**As a** server owner, **I want** the setup to add only what is missing, **so that** my existing web app is never affected.

## Acceptance criteria

**AC-1** — *Given* a server with other apps, *when* `setup-droplet.sh` runs, *then* firewall, open ports, environment variables and sysctl are unchanged and no running service/container is restarted.

**AC-2** — *Given* Docker / swap already present, *when* the script runs, *then* they are left unchanged.

**AC-3** — *Given* apt is busy, *when* the script runs, *then* it waits with progress output instead of failing or hanging.
