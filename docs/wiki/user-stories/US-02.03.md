## Story

**As a** bot operator, **I want** a clear error when the webhook URL is wrong or deleted, **so that** I fix the configuration instead of losing messages silently.

## Acceptance criteria

**AC-1** — *Given* the webhook returns 401/403/404 on posting, *when* the cycle runs, *then* a CRITICAL log is written, the bot exits with code 3 and no war's attempts are used up.
