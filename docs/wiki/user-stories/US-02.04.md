## Story

**As a** Discord server admin, **I want** an optional role mention on each war message, **so that** interested members get a notification.

## Acceptance criteria

**AC-1** — *Given* `mention_role_id` is set, *when* a war is posted, *then* the message pings exactly that role and nobody else (`allowed_mentions`).

**AC-2** — *Given* `mention_role_id` is empty, *when* a war is posted, *then* nobody is pinged, also not by `@everyone` in a name.
