## Story

**As a** Discord server admin, **I want** the bot not to post the ~60 wars that already exist when it starts, **so that** the channel is not flooded on day one.

## Acceptance criteria

**AC-1** — *Given* an empty database and `bootstrap_silent: true`, *when* the first cycle runs, *then* all listed wars are stored as `skipped` and nothing is posted.

**AC-2** — *Given* the bootstrap is done, *when* a war appears that was not listed before, *then* it is posted.
