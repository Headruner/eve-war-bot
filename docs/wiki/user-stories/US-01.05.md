## Story

**As a** Discord server admin, **I want** the bot not to post old wars when it starts for the first time, **so that** the channel is not flooded on day one.

## Acceptance criteria

**AC-1** — *Given* an empty database and `bootstrap_silent: true`, *when* the first cycle runs, *then* the newest war ID becomes the watermark and nothing is posted.

**AC-2** — *Given* the bootstrap is done, *when* ESI lists a war with a higher ID, *then* it is posted.
