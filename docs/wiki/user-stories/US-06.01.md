## Story

**As a** server owner, **I want** the bot isolated and limited, **so that** it can never starve my other apps.

## Acceptance criteria

**AC-1** — *Given* the container runs, *when* `docker stats` is checked, *then* memory limit is 256 MiB and the bot uses < 100 MiB; CPU ≤ 0.5 core.

**AC-2** — *Given* the container, *when* it is inspected, *then* user is non-root (uid 10001), root filesystem read-only, all capabilities dropped, no published ports.
