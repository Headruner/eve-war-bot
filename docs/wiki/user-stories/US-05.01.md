## Story

**As a** bot operator, **I want** one JSON file with empty fields for all secrets, checked at start, **so that** I can't start the bot with a broken configuration.

## Acceptance criteria

**AC-1** — *Given* `credentials.example.json`, *when* I copy it to `credentials.json`, *then* it contains `discord.webhook_url`, `discord.mention_role_id`, `esi.contact`.

**AC-2** — *Given* an empty webhook, invalid JSON, a non-numeric role ID or a folder instead of the file, *when* the bot starts, *then* it stops with exit code 2 and a message naming the problem.

**AC-3** — *Given* the repository and the image, *when* they are built or pushed, *then* `credentials.json` is never included (`.gitignore`, `.dockerignore`).
