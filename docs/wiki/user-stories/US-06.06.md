## Story

**As a** server owner, **I want** to undo what the earlier setup script changed, **so that** my server is back to its previous state.

## Acceptance criteria

**AC-1** — *Given* `--dry-run`, *when* the script runs, *then* it only lists what it would revert.

**AC-2** — *Given* each item, *when* the script runs, *then* it reverts only what the earlier script provably changed (apt history, file contents) and asks before every change.

**AC-3** — *Given* other containers exist or Docker is not reachable, *when* Docker removal is considered, *then* Docker is not removed.
