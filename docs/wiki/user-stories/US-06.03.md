## Story

**As a** bot operator, **I want** to see whether the bot is healthy and not fill the disk with logs, **so that** I can trust it to run unattended.

## Acceptance criteria

**AC-1** — *Given* no successful cycle for 2 × interval + 5 min, *when* Docker runs the health check, *then* the container is reported `unhealthy`.

**AC-2** — *Given* the bot has run for weeks, *when* the log size is checked, *then* it is at most 3 × 5 MB.
