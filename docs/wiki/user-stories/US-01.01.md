## Story

**As a** Discord server admin, **I want** the bot to check EVE Online's official API for new wars on a fixed schedule, **so that** new wars reach us without anyone watching a website.

## Acceptance criteria

**AC-1** — *Given* the bot is running with `poll_interval_min: 15`, *when* 15 minutes pass, *then* a cycle runs and logs `ESI: N war IDs listed, M new.`.

**AC-2** — *Given* ESI's cached `/wars/` response has not expired yet, *when* a cycle runs, *then* no request is sent to ESI; the cached list is used.

**AC-3** — *Given* ESI is unreachable or answers 5xx, *when* a cycle runs, *then* `ESI error: ...` is logged, the service keeps running and retries next cycle.

## Notes

Since 2.0 the source is ESI `GET /wars/`; 1.x parsed the DOTLAN wars page. ESI caches `/wars/` for up to 1 h, so detection takes about 15–75 minutes after the declaration.
