## Story

**As a** Discord server admin, **I want** restarts and upgrades not to repeat old wars, **so that** the channel stays clean.

## Acceptance criteria

**AC-1** — *Given* posted wars, *when* `docker compose down` + `up`, image rebuild or server reboot, *then* no war is posted again and pending wars are still sent.

**AC-2** — *Given* a database from an older version, *when* the new version starts, *then* it is migrated automatically, keeping all rows.
