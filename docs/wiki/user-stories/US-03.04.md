## Story

**As a** Discord member, **I want** to see which structures the aggressor and the defender corporation own, **so that** I can judge targets and staging systems without searching other sites.

## Acceptance criteria

**AC-1** — *Given* a war where a party is a corporation and the dataset lists structures owned by it, *when* the message is built, *then* a field `🏯 Aggressor structures (N)` / `🏯 Defender structures (N)` shows counts per type (e.g. `Astrahus ×2 · Raitaru ×1`), the top 3 systems and up to `structures.max_listed` structures as `name (type)`.

**AC-2** — *Given* a party with no structure in the dataset, *when* the message is built, *then* the field says `none publicly known`.

**AC-3** — *Given* more structures than `max_listed`, *when* the message is built, *then* the list ends with `… N more`.

**AC-4** — *Given* any war party with an entity ID, *when* the message is built, *then* the structures field and the Links field contain a link to the Adam4EVE structure search for that party (`structures.php?corp=<id>` or `?alliance=<id>`), so readers can open the full, filterable list; the bot itself never reads Adam4EVE.
