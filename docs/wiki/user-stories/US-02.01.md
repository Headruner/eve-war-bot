## Story

**As a** Discord member, **I want** a message in our channel for every new war, **so that** we can react to war declarations quickly.

## Acceptance criteria

**AC-1** — *Given* a new war and a valid webhook, *when* the cycle runs, *then* one message is posted and the war is stored as `sent` with the Discord message ID.

**AC-2** — *Given* Discord returns an error, *when* posting fails, *then* the war stays `pending` and is retried in the next cycle (max `max_attempts`).
