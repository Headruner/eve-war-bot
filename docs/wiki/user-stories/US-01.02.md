## Story

**As a** bot operator, **I want** every row of the wars table converted into structured data, **so that** messages contain correct parties, dates and status.

## Acceptance criteria

**AC-1** — *Given* a DOTLAN wars page, *when* it is parsed, *then* each row yields war ID, both parties (name, type, entity ID, members), declared time (UTC) and status.

**AC-2** — *Given* the date is written as `HH:MM:SS YYYY-MM-DD` or `YYYY-MM-DD HH:MM:SS`, *when* it is parsed, *then* both give the same UTC timestamp.
