## Story

**As a** developer, **I want** one command that tests, builds and pushes the image to Nexus, **so that** servers can pull a ready image.

## Acceptance criteria

**AC-1** — *Given* `nexus.env` with registry and user, *when* `publish-nexus.ps1` / `.sh` runs, *then* tests run (if pytest present), a linux/amd64 image is pushed as `:<version>` and `:latest`, and the server commands are printed.
