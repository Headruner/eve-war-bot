## Story

**As a** Discord server admin, **I want** to group wars into one message when many arrive, **so that** the channel stays tidy.

## Acceptance criteria

**AC-1** — *Given* `batch_embeds: 10` and 4 new wars, *when* the cycle runs, *then* one message with 4 embeds is posted; each banner is attached and referenced.
