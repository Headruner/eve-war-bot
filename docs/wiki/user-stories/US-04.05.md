## Story

**As a** Discord member, **I want** war notifications even if CCP's API is unavailable, **so that** the core function never depends on the extra report.

## Acceptance criteria

**AC-1** — *Given* ESI is unreachable, *when* a new war is posted, *then* the message is sent without the report section and a warning is logged; the report is added by a later live update.
