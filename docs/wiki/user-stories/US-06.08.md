## Story

**As a** server owner, **I want** to get compose file, config templates and scripts from the image with one command, **so that** the server needs no git checkout.

## Acceptance criteria

**AC-1** — *Given* an empty folder, *when* `docker run … <image> install` runs, *then* docker-compose.yml, .env, config/*, scripts/*, DEPLOY.md are written.

**AC-2** — *Given* existing config, credentials and .env, *when* `install --force` / `bot.sh update` runs, *then* they are kept; only managed files are refreshed.
