## Story

**As a** developer, **I want** tests and image build on every push, **so that** broken changes are caught before deployment.

## Acceptance criteria

**AC-1** — *Given* a push to `main`, *when* GitHub Actions runs, *then* tests pass and the image is pushed to GHCR (`latest`, `sha`).

**AC-2** — *Given* a pull request, *when* GitHub Actions runs, *then* only the tests run.
