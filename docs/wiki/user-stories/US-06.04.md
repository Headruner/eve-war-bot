## Story

**As a** bot operator, **I want** simple commands for check, test, start, logs, status, update, backup, stats, **so that** I don't have to remember Docker commands.

## Acceptance criteria

**AC-1** — *Given* the project folder, *when* I run `bash scripts/bot.sh <command>`, *then* the command does what its help line says and prints the result.

**AC-2** — *Given* `credentials.json` is missing or a folder, *when* I run `start`, `check` or `test`, *then* it stops with a hint how to fix it.
