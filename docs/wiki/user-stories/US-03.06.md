## Story

**As a** Operator, **I want** the structure data to refresh by itself and never break posting, **so that** the bot keeps running on the small shared server.

## Acceptance criteria

**AC-1** — *Given* `structures.enabled: true`, *when* the dataset is older than `structures.refresh_hours` (default 24), *then* it is downloaded with `If-None-Match`/`If-Modified-Since`, parsed as a stream into the SQLite table `structures`, and the log shows `Structures dataset loaded: N structures`; a 304 keeps the stored data.

**AC-2** — *Given* the download fails or the dataset is broken, *when* a cycle runs, *then* a warning is logged, the old data (if any) is kept, it is retried after 1 h and wars are posted without the structures field.

**AC-3** — *Given* `structures.enabled: false`, *when* the bot runs, *then* the dataset is never downloaded and messages have no structures field.
