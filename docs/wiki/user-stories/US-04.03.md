## Story

**As a** Discord member, **I want** the war report in the message to stay current, **so that** I don't need a new message for every kill.

## Acceptance criteria

**AC-1** — *Given* a posted war and `live_updates: true`, *when* `update_interval_min` has passed and the score changed, *then* the same Discord message is edited (PATCH), no new message.

**AC-2** — *Given* the report did not change, *when* the interval passes, *then* no edit is sent.

**AC-3** — *Given* the message was deleted in Discord, *when* an update is due, *then* updates for it stop.
