## Story

**As a** bot operator, **I want** behaviour settings in `config.yaml`, **so that** I can change interval, filters or images without code.

## Acceptance criteria

**AC-1** — *Given* I change a value in `config.yaml`, *when* I run `bot.sh restart`, *then* the new value is used (shown in the start log where applicable).

**AC-2** — *Given* a key is missing, *when* the bot starts, *then* the documented default is used.
